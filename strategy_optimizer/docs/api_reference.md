# API Reference

This document provides a detailed reference for the APIs and interfaces exposed by various components of the Strategy Optimizer.

---

## **Component APIs**

Each major component within the `src/` directory defines a set of public methods and interfaces. This section will detail these, including:

-   **Class/Module Name:** `src/path/to/module.py`
-   **Purpose:** Brief description of the module's role.
-   **Public Methods:**
    -   `method_name(parameter_name: type, ...)`: Description, arguments, return type.
    -   Example usage.

---

## **Data Schemas**

All data structures are defined using Pydantic models in `src/data_bus/schemas.py`. Refer to that file for the most up-to-date and authoritative schema definitions.

### `Candle`

Represents a single OHLCV (Open, High, Low, Close, Volume) data point.

```python
# Defined in src/data_bus/schemas.py
from pydantic import BaseModel
from datetime import datetime

class Candle(BaseModel):
    timestamp: datetime
    open: float
    high: float
    low: float
    close: float
    volume: float
```

### `OptimizerProposal`

Details a strategy parameter proposal generated by the optimizer.

```python
# Defined in src/data_bus/schemas.py
from pydantic import BaseModel, Field
from typing import List, Dict, Any
from datetime import datetime
import uuid

class CausalChainRef(BaseModel):
    type: str
    id: str

class OptimizerProposal(BaseModel):
    proposal_id: str = Field(default_factory=lambda: str(uuid.uuid4()))
    timestamp: datetime = Field(default_factory=datetime.utcnow)
    proposal_version: int
    source: str
    proposed_parameters: Dict[str, Any]
    context: Dict[str, Any]
    causal_chain_refs: List[CausalChainRef]
```

### `AuditVerdict`

The result of the audit process for a given proposal.

```python
# Defined in src/data_bus/schemas.py
from pydantic import BaseModel, Field
from typing import List, Dict, Any, Optional
from datetime import datetime

class TieredFinding(BaseModel):
    tier: str
    code: str
    explanation: str
    impact: Optional[str] = None
    remediation: Optional[str] = None

class AuditAction(BaseModel):
    type: str
    restrictions: Optional[Dict[str, Any]] = None

class AuditVerdict(BaseModel):
    audit_id: str = Field(default_factory=lambda: str(uuid.uuid4()))
    proposal_id: str
    timestamp: datetime = Field(default_factory=datetime.utcnow)
    tiered_findings: List[TieredFinding]
    action: AuditAction
    artifact_refs: List[str]
    checksum: str
```

### `BacktestResult`

Summarizes the outcome of a strategy backtest.

```python
# Defined in src/data_bus/schemas.py
from pydantic import BaseModel
from typing import List
from datetime import datetime

class BacktestResult(BaseModel):
    start_date: datetime
    end_date: datetime
    profit_factor: float
    max_drawdown_pct: float
    total_trades: int
    win_rate: float
    sharpe_ratio: float
    sortino_ratio: float
    equity_curve: List[float]
```

## **Configuration Parameters**

Refer to the `.env.example` file and the YAML files in the `config/` directory for configurable parameters and their descriptions.

-   **`.env.example`**: Environment variables for API keys and sensitive settings.
-   **`config/system_config.yaml`**: General system settings, paths, and global thresholds.
-   **`config/audit_rules.yaml`**: Definitions for T1, T2, and T3 audit checks.
-   **`config/regime_config.yaml`**: Thresholds for market regime classification.
-   **`config/parameter_bounds.yaml`**: Min/max ranges for strategy parameters.
-   **`config/safe_baseline.yaml`**: Default parameters for emergency fallback mode.
